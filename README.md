 Questionário teórico

1. O que é um contêiner?
É um ambiente isolado que executa uma aplicação com tudo o que ela precisa para funcionar.

2. Qual é a função do Docker em relação aos contêineres?
O Docker permite criar, executar e administrar contêineres de aplicações.

3. Para que o Kubernetes pode ser utilizado?
Pode ser usado para gerenciar e organizar aplicações que funcionam em contêineres.

4. Qual é a diferença entre monitoramento e logs?
O monitoramento verifica o funcionamento e o desempenho do sistema, enquanto os logs registram informações, eventos e erros.

5. Se um microsserviço começar a receber muitos acessos, qual solução pode ser utilizada para reduzir a sobrecarga?
É possível criar mais instâncias do microsserviço e dividir os acessos entre elas, diminuindo a carga em cada instância.
